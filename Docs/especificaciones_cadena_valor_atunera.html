⚙️ Estructura de la Jerarquía de Herencia en Java

1. Superclase: public class EtapaProceso

Contiene los datos comunes a toda etapa operativa y define el contrato de métodos que cada subclase especializará:

  • protected String codigoLote: Identificador del lote (ej: "LOTE-2026-001").
  • protected String fecha: Fecha u hora de ejecución (ej: "04/11/2026").
  • protected String responsable: Nombre del operador responsable (ej: "Carlos Mendoza").
  • protected String nombreEtapa: Nombre legible de la etapa (ej: "Control de Calidad").
  • public boolean validarInvariante(): Retorna verdadero o falso según las reglas de cada subclase.
  • public void mostrarResumen(): Imprime en consola en una sola línea el estado de la etapa.

public class RecepcionMuelle extends EtapaProceso

Atributos propios: nombreBarco, pesoBruto, taraCamion.

Constructor invoca super(...). Sobreescribe validarInvariante() retornando true si el peso bruto es mayor a la tara y el peso neto es positivo.

public class ControlCalidad extends EtapaProceso

Atributos propios: temperaturaMuestra, codigoSonda.

Constructor invoca super(...). Sobreescribe validarInvariante(): retorna true únicamente si la temperatura interna es ≤ 4.0 °C.

public class ProduccionFileteo extends EtapaProceso

Atributos propios: pesoInicial, pesoLomos, pesoMerma.

Constructor invoca super(...). Valida que el rendimiento de lomos ((pesoLomos / pesoInicial) * 100) se ubique en el rango óptimo de 45.0% a 51.0%.

public class AlmacenamientoBodega extends EtapaProceso

Atributos propios: codigoTina, pesoTinaKg, temperaturaCamara.

Constructor invoca super(...). Valida que la tina pese entre 600.0 y 605.0 kg y la cámara de frío opere a ≤ -18.0 °C.

public class DespachoExportacion extends EtapaProceso

Atributos propios: codigoContenedor, antiguedadMeses, paisDestino.

Constructor invoca super(...). Valida que la antigüedad del lote sea estrictamente menor a 1.0 mes para ser apto de exportación inmediata.
